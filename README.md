# 이가네 복숭아

픽셀 그래픽으로 만든 방치형 복숭아 농장 게임이에요. 가끔 들어와서 나무를 톡톡 눌러 돌봐 주면 됩니다.

## 노는 법
- 나무를 누르면 그때 필요한 일을 알아서 해요. 물방울 말풍선이 뜨면 물 주기, 가위가 뜨면 가지치기, 복숭아가 뜨면 수확이에요.
- 할 일이 없을 때 누르면 쓰담쓰담 해서 조금 더 빨리 자라요.
- 흰 바탕에 노란 얼룩 고양이가 나무 옆에서 낮잠을 자면 그 나무는 안 자라고 물도 빨리 말라요. 세 번 눌러서 쫓아내면 코인을 줘요. 한 번 누를 때마다 도망 다녀요.
- 새는 익은 복숭아를 쪼아 먹어요. 눌러서 쫓아내세요.
- 앱을 꺼 둬도 시간은 흘러요. 물이 다 마르면 성장이 멈춥니다.
- 하늘은 실제 시간에 맞춰 낮, 노을, 밤으로 바뀌어요.
- 계절도 실제 달력을 따라가요. 봄엔 꽃잎, 가을엔 단풍과 낙엽, 겨울엔 눈이 내리고 계절마다 열리는 품종이 달라요.

## 새로 들어간 것들
- 밭 개척: 앞밭, 개울가 밭(농장 Lv 4, 900코인), 언덕 밭(농장 Lv 8, 3000코인)까지 최대 18그루. 화면 양옆 화살표로 밭을 오가고, 화살표에 빨간 점이 뜨면 그쪽 밭에 할 일이 있다는 뜻이에요. 개척하면 나무 2그루가 바로 심어져요.
- 품종 도감: 15가지 품종을 모아요. 처음 수확한 품종은 20코인을 줘요. 하트복숭아(쓰담쓰담 많이 받은 나무), 냥복숭아(고양이와 단짝)처럼 특별한 품종도 있어요.
- 고양이 호감도: 고양이가 오면 오른쪽 아래 '츄르 주기'(10코인)로 친해져요. 20이면 이름 짓기, 50이면 나무 방해 안 하고 선물 두고 가기, 80이면 새를 대신 쫓아 주고 냥복숭아가 열려요.
- 출석 보상: 하루에 한 번, 7일 주기로 코인을 받고 7일째엔 황금 복숭아도 줘요.
- 주막 오늘의 메뉴: 매일 메뉴 하나가 40% 할인돼요.
- 마을 의뢰판: 왼쪽 위 게시판. 마을 사람들 부탁(최대 3개)을 들어주면 시장보다 비싸게 쳐 줘요. 새 부탁은 90분마다 와요.
- 꾸미기: 바람개비, 우체통, 꽃밭, 청사초롱, 장독대, 연못, 원두막. 하나마다 판매가 +5%. 우체통을 누르면 농장 일기가 열려요.
- 농장 일기: 진짜 농장 소식. 새 글이 올라오면 '진짜 농장' 버튼에 빨간 점이 떠요. shopUrl을 넣으면 게임을 켤 때 한 번 판매 시작 알림이 떠요.

## 오늘의 농장 (위쪽 Lv 버튼)
- 오늘의 할 일: 매일 3개(Lv 9부터 4개)의 할 일이 나와요. 하나 끝낼 때마다 15코인, 다 끝내면 보상 상자(코인 + 황금 복숭아나 성장 버프).
- 놀이
  - 복숭아 받기 (Lv 2): 30초 동안 떨어지는 복숭아를 바구니로 받아요. 벌레는 -3점. 점수만큼 코인. 하루 3판(Lv 7부터 4판). 왼쪽 위 바구니를 눌러도 돼요.
  - 고양이와 놀아 주기 (Lv 3, 호감도 50 이상): 고양이가 오면 '놀아 주기' 버튼이 떠요. 15초 동안 강아지풀을 흔들어 주면 호감도와 코인을 받아요.
- 깜짝 손님: 가끔 황금 나비(15코인), 반짝이는 옛날 동전(5~20코인)이 나타나요. Lv 6부터는 떠돌이 행상이 와서 성장 촉진제, 츄르 꾸러미, 희귀 접순, 황금 거름을 팔아요.
- 농장 레벨: 복숭아 1개 수확할 때마다 경험치 1, 의뢰 15, 할 일 10, 보상 상자 30, 놀이 점수에 따라 경험치를 얻어요. 레벨이 오르면 새 밭(Lv 4, 8), 꿀벌통(Lv 5), 꾸미기(솟대 Lv 3, 돌탑 Lv 6), 놀이, 행상이 열리고, 울타리 너머 마을에 초가집, 기와집, 물레방아, 장터, 학교, 느티나무가 하나씩 생겨요.
- 내 농장 자랑하기: 농장 레벨 화면이나 레벨업 창에서 지금 농장 모습을 카드 이미지로 만들어 공유해요. 공유가 안 되는 브라우저에서는 이미지를 길게 눌러 저장하면 돼요.

## 농사 이벤트
- 봉지 씌우기: 풋복숭아 단계에서 나무를 누르면 봉지를 씌워요. 새가 못 먹고, 수확할 때 2개 더 얻어요.
- 벌레 잡기: 가끔 나무에 분홍 애벌레가 붙어요. 톡 잡으면 2코인, 놔두면 그 나무가 절반 속도로 자라요.
- 날씨: 비 오는 시간엔 물이 저절로 차요(겨울엔 함박눈). 비 그친 뒤 무지개가 뜨면 황금 복숭아 확률이 올라가요. 여름과 가을엔 가끔 태풍 예보가 오고, 90초 안에 나무를 눌러 지지대를 세우면 무사해요. 다 막으면 30코인.
- 꿀벌통(농장 Lv 5부터 상점 250코인): 벌이 꽃 핀 나무를 오가며 복숭아가 하나 더 열려요. 2시간마다 꿀이 모이고, 눌러서 25코인을 받아요.
- 나무 나이: 수확할수록 나무가 자라요. 5번 튼튼한 나무(+1개), 15번 어른 나무(+2개), 40번 할아버지 나무(+3개). 수첩 > 나무에서 이름을 지어 줄 수 있어요.
- 명절 이벤트: 복날(7/10~8/20) 주막 삼계탕, 추석(앞 7일~뒤 2일) 선물세트 의뢰와 보름달, 크리스마스(12/18~12/26) 눈사람과 트리 전구, 출석 선물 50코인. 날짜는 `EVENTS`에서 바꿀 수 있고, 추석은 연도별 날짜를 적어 둬야 해요.
- 쿠폰 도전 (지금은 숨김): `REAL_FARM.showCoupons`를 `true`로 바꾸면 진짜 농장 화면에 도감 완성, 500개 수확, 고양이 단짝 목표가 나타나요. `REAL_FARM.coupons`의 `code`에 쿠폰 번호를 넣으면, 달성한 사람에게 번호와 복사 버튼이 보여요.

## 배경음악
게임 안에서 직접 연주되는 오리지널 칩튠이에요. 음원 파일 없이 코드(Web Audio)로 만든 곡이라 외부 저작권이 걸려 있지 않아요.
- 낮에는 통통 튀는 칩튠, 밤에는 느린 자장가 버전, 겨울에는 종소리 버전으로 바뀌어요.
- 오른쪽 위 음표 버튼으로 배경음악, 스피커 버튼으로 효과음을 따로 켜고 끌 수 있어요.
- 브라우저 정책상 화면을 한 번 터치해야 음악이 시작돼요.
- 멜로디는 index.html의 `SONG_MEL`, 베이스는 `SONG_BASS`에서 바꿀 수 있어요.

## 이가네 주막
모은 코인으로 음식을 사 먹으면 농사에 도움이 되는 효과가 생겨요. 10번 먹으면 단골 서비스로 30코인을 받아요.
- 막걸리 15코인: 30분 동안 황금 복숭아 확률 2배
- 파전 25코인: 모든 나무에 물 가득
- 새우구이 40코인: 다음 수확 3번은 복숭아 +2개씩
- 바베큐 60코인: 1시간 동안 성장 1.5배

메뉴와 가격은 index.html의 `MENU`에서 바꿀 수 있어요.

## 진짜 농장 정보 넣기
index.html 위쪽의 `REAL_FARM` 부분만 바꾸면 돼요.
- `name` 농장 이름
- `shopUrl` 판매 페이지 주소. 비워 두면 "복숭아 구매하러 가기"를 눌렀을 때 `comingSoon` 문구가 떠요. 주소를 넣으면 그 페이지로 바로 이동해요.
- `bank`, `account`, `holder` 냉수 한잔(후원) 계좌 정보. 복사 버튼은 GitHub Pages(https)에서 잘 동작해요.
- `diary` 농장 일기. 지금 들어 있는 글은 예시라서 실제 내용으로 바꿔 주세요. 새 글은 맨 위에 `{date:'2026-11-01', title:'제목', text:'내용', photo:'photos/1.jpg'}` 형태로 추가하면 돼요. 사진을 쓰려면 저장소에 photos 폴더를 만들어 올리면 돼요.

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `peach-farm`).
2. 압축을 푼 파일과 폴더를 전부 올려요: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`, `android` 폴더, `.github` 폴더
3. 저장소 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 두고 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/peach-farm/` 에서 열려요.
5. 휴대폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.

## 손보기 좋은 곳 (index.html 위쪽 설정 부분)
- `STAGE_MIN` 단계별 성장 시간(분)
- `WATER_MIN` 물이 다 마르는 시간(분)
- `PRUNE_MIN` 가지가 무성해지는 시간(분)
- `FIELDS` 밭 이름과 개척 가격, `SLOT_COST` 나무 자리 가격(18칸), `UPGRADES` 가격
- `PEACH_PRICE`, `GOLD_PRICE` 판매가
- `VARIETIES` 품종 이름, 계절, 가격
- `XP_NEED` 레벨별 필요 경험치, `UNLOCKS` 레벨별 해금 목록, `QUESTS` 할 일 목록, `PEDDLER` 행상 물건
- `TREE_LV` 나무 나이 단계, `HONEY_HOURS`/`HONEY_COINS` 꿀벌통, `EVENTS` 명절 날짜
- `DECOS` 꾸미기 가격, `CLIENTS` 의뢰하는 마을 사람들, `CHURU` 츄르 가격, `ATT_REWARD` 출석 보상

저장은 브라우저 localStorage에 돼요. 다른 기기와는 공유되지 않아요.

## 아이폰 설치 안내
아이폰에서 처음 열면 홈 화면에 추가하는 방법이 자동으로 떠요. 카카오톡으로 링크를 열었다면 Safari로 열기 버튼이 먼저 나와요. 안내는 ? 버튼 안의 "홈 화면에 앱으로 추가하기"로 다시 볼 수 있어요.

참고로 아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로라서, 홈 화면 앱으로 처음 열면 농장이 새로 시작돼요.

## 안드로이드 앱(APK)
`android` 폴더는 게임 주소를 그대로 여는 안드로이드 앱이에요. 웹(index.html)을 고치면 앱에도 바로 반영되고, APK를 다시 만들 필요는 없어요.

APK는 GitHub가 자동으로 만들어 줘요.
1. `android` 폴더와 `.github` 폴더를 저장소에 올리면, 저장소 Actions 탭에서 "안드로이드 APK 만들기"가 돌아가요 (3~5분).
2. 끝나면 저장소 오른쪽 Releases에 `igane-peach.apk`가 올라와요.
3. 받는 주소: `https://github.com/아이디/저장소이름/releases/latest/download/igane-peach.apk`
   게임 안 안드로이드 설치 안내에도 이 주소로 가는 버튼이 들어 있어요.

`.github` 폴더가 안 올라갔다면 (맥에서는 점으로 시작하는 폴더가 숨겨져 있어요):
GitHub 저장소에서 Add file → Create new file을 누르고, 파일 이름에 `.github/workflows/android.yml`을 입력한 다음 `android/workflow-copy.yml`의 내용을 붙여넣고 Commit 하면 돼요.

Actions 탭에서 직접 다시 돌리고 싶으면 "안드로이드 APK 만들기" → Run workflow를 누르면 돼요.

참고
- 앱이 여는 주소는 저장소 이름으로 자동으로 정해져요 (`https://아이디.github.io/저장소이름/`).
- APK 서명 키(`android/app/peach.keystore`)가 저장소에 같이 들어 있어요. 같은 키로 계속 빌드돼야 업데이트 설치가 되니 지우지 마세요.
- 플레이스토어에 올릴 게 아니라 파일로 나눠 주는 방식이라, 설치할 때 "출처를 알 수 없는 앱 허용"을 한 번 켜야 해요.
